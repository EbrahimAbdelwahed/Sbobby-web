# Log: mobile skip program review

Date: 2026-05-25 23:15
Area: sbobby-web

## Summary

Implemented a mobile-study skip review flow. When a user skips a question, the client now posts to a dedicated server route that creates a deduplicated `skip_possible_out_of_program` report and starts a DeepSeek v4 flash program-eligibility review after the response.

The automation is conservative: high-confidence `out_of_program` results set `program_eligible = false`, record the model rationale in `admin_note`, resolve the skip report, and write an `agent_review_logs` entry. High-confidence `in_program` results dismiss the automatic report. Uncertain or low-confidence results leave the report in `reviewing` for admin inspection.
